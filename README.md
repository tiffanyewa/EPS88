# EPS88 – Python for Earth Science (UC Berkeley)

Coursework completed as part of EPS88, taught by Prof. Gleeson at UC Berkeley.

## Contents
Weekly Jupyter notebooks and homework assignments covering Python for Earth Science data analysis. Topics progress from NumPy and Pandas fundamentals through probability, error propagation, correlation, regression, clustering, and classification. All applied to real Earth science datasets including earthquake catalogs, CO2 records, and glacial cycles.

All notebooks were completed independently by Tiffany Ajayi as part of course assignments.
Starter code and problem sets are credited to the course instructors.
